## FAQ

### Is OmniPatch safe to use on my computer?

OmniPatch is scanned for vulnerabilities and is designed to modify local application files only. It does not contain or install any malicious software, but modifying software may trigger false positives from some anticomponent programs.

### Which AI applications are currently supported?

OmniPatch currently supports ChatGPT (Web/Desktop), Claude, Microsoft Copilot, GitHub Copilot, Cursor, Devin, and JetBrains AI Assistant. We are actively working to add support for more tools.

### How often is OmniPatch updated?

We aim to release updates within a few days after any of the supported AI applications receives a major update that might affect patch compatibility. Check the GitHub repository for the latest releases.

### Will my account be banned for using OmniPatch?

OmniPatch works by modifying the local client, not by interacting with servers. While it is designed to be undetectable, any modification of software terms of service carries inherent risk, and we cannot guarantee account safety.

### Do I need an internet connection to run OmniPatch?

You need an internet connection to download OmniPatch and to use the AI applications themselves. The patcher itself can be run offline after download, as it modifies local files.

### Can I use OmniPatch on a Mac or Linux?

No, OmniPatch is currently a Windows-only desktop application (.exe). Development for other operating systems is not planned at this time.

### What does the password 'omnipatch' protect?

The password is used for the ZIP archive to prevent automated scanning and distribution. It ensures the file is only used by users who intentionally seek it out and follow the instructions.
